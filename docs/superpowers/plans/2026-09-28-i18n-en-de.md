# Multilingual site (en-GB, de-DE) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Serve the whole site in en-GB at `/` and de-DE at `/de/`, offer German to German-language browsers, and remember an explicit choice.

**Architecture:** One `<App lang>` rendered twice at build time from typed dictionaries (`src/i18n/en.ts`, `de.ts`). Head metadata comes from the same dictionaries through `src/i18n/head.ts`, injected by a Vite plugin (English, dev and build) and rewritten by the prerender for German. A single inline script (`src/i18n/inline.ts`) handles the stored-choice redirect and the offer bar on every home and article page, so neither is ever part of prerendered markup.

**Tech Stack:** React 18, Vite 5, TypeScript, Tailwind, tsx scripts, gray-matter/marked, Vitest (new, dev only).

**Spec:** `docs/superpowers/specs/2026-09-28-i18n-en-de-design.md`

## Global Constraints

- No i18n library. No new runtime dependency. Vitest is the only new dev dependency.
- Both `pnpm-lock.yaml` and `package-lock.json` updated for any dependency change.
- Everything TypeScript; scripts run through `tsx`.
- No `window`/`document`/`localStorage` during render.
- Editorial rules for all copy: no em or en dashes in prose (date ranges and title separators excepted); collective voice ("we" / "wir", "our team" / "unser Team") for delivery claims; first person singular only for title, leadership scope, what he is looking for, working style.
- Headline EN: `Lead Software Engineer · Agentic AI & LLM Platforms · TypeScript / AWS`. DE: `Lead Software Engineer · Agentic AI & LLM-Plattformen · TypeScript / AWS`.
- Citizenship (German and Croatian) stated. Permanent, fully remote employment only; never freelance/contract; never immediate availability.
- English copy moves verbatim. No English wording changes.
- Detection: `navigator.languages` entry equal to `de` or starting with `de-`, case-insensitive. Offer only; never redirect on detection.
- Storage key `lang`, values `en` | `de`, written only on explicit click, every access in `try/catch`.
- Legal translations as close to the German as possible, no "German prevails" line.

## Deviations from the spec (found while reading the code)

- The offer bar is fixed to the **bottom** of the viewport, not above the header: the header is fixed and slides in on hover over the top 10 %, so a top bar would be covered.
- The offer bar is one inline script shared by home and article pages rather than a React component on the home page plus a script on articles. Same behaviour, one implementation, and it is never in prerendered markup by construction.
- There is no mobile menu (`nav` is `hidden md:block`). The switcher goes into the always-visible right-hand header group. The two `de | en` CV buttons there are replaced by one CV link in the active language, so there is no second "de | en" next to the site switcher.
- German legal pages' back link goes to `/de/`.

## Review Focus

1. Visitor with stored `de` opens an English article that has no German translation: redirect must land on the German fallback page, never a 404. Test: `counterpartPath` + generator always writes `/de/writing/<slug>/`; build test asserts every English article has a German page.
2. Storage throws (Safari private mode, blocked site data): offer still appears, clicking still navigates, nothing throws. Test in `inline.test.ts`.
3. Hydration mismatch on `/de/`: client must resolve the same language the server rendered. Test: build test asserts `dist/de/index.html` root contains German strings; `langFromPath('/de/')` and `langFromPath('/de')` both `de`.
4. German page shipped with English head (title/canonical/og). Prerender throws if the head markers are missing; build test asserts German title, canonical `/de/`, `og:locale` `de_DE`.
5. Offer bar or redirect leaking onto German pages: script guards on path. Tests for `/de/` and `/de/writing/x/` in `inline.test.ts`.

```ts
// src/i18n/paths.ts
import type { Lang } from './lang';

export const langFromPath = (pathname: string): Lang =>
  pathname === '/de' || pathname.startsWith('/de/') ? 'de' : 'en';

export function counterpartPath(pathname: string, target: Lang): string {
  if (langFromPath(pathname) === target) return pathname;
  if (target === 'de') return `/de${pathname}`;
  return pathname.slice(3) || '/';
}

export const homePath = (lang: Lang): string => (lang === 'de' ? '/de/' : '/');
```

```ts
// src/i18n/preference.ts
import type { Lang } from './lang';

export const STORAGE_KEY = 'lang';

const browserStorage = (): Storage | null => window.localStorage;

export function readStoredLang(get: () => Storage | null = browserStorage): Lang | null {
  try {
    const value = get()?.getItem(STORAGE_KEY);
    return value === 'en' || value === 'de' ? value : null;
  } catch {
    return null;
  }
}

export function storeLang(lang: Lang, get: () => Storage | null = browserStorage): void {
  try {
    get()?.setItem(STORAGE_KEY, lang);
  } catch {
    // Blocked storage only means the choice is not remembered.
  }
}

export const prefersGerman = (languages: readonly string[]): boolean =>
  languages.some(l => /^de(-|$)/i.test(l));
```

### Task 2: The inline language script

**Files:**
- Create: `src/i18n/inline.ts`
- Test: `src/i18n/inline.test.ts`

**Interfaces:**
- Consumes: the rules of Task 1 (same regex, key and path mapping), restated in ES5 because the script ships inline, unbundled.
- Produces: `languageScript: string` (IIFE, safe on every page), `storeOnClick(lang: Lang): string` (value for an `onclick` attribute).

Behaviour of `languageScript`:
1. If the path is German (`/de` or `/de/...`), do nothing.
2. Read `localStorage.lang` in `try/catch`. If `de`: `location.replace('/de' + pathname + search + hash)` and stop. If `en`: stop.
3. If no `navigator.languages` entry matches `^de(-|$)`, stop.
4. On `DOMContentLoaded` (or immediately if already parsed) append to `body` a `<div lang="de" role="region" aria-label="Sprachauswahl">` fixed to the bottom: text "Diese Seite gibt es auch auf Deutsch.", an `<a>` "Auf Deutsch lesen" to the German counterpart that stores `de` on click, a `<button>` "English" that stores `en` and removes the bar. Inline styles only: black background, white text, 1px white top border, Space Grotesk/Inter fallbacks, wraps on narrow screens.

  };
  const location = { pathname: env.path, search: '', hash: '', replace };
