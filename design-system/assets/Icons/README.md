# Icons

Hand-picked Heroicons v1 outline paths (24px grid) plus the LinkedIn and GitHub brand glyphs, copied verbatim from the site. Files are drawn in black (`#000000`) because `<img>` cannot inherit colour; in product code use the `Icon` component, which inlines them with `currentColor` so they take `ink` or `ink-muted`.

Stroke weights are part of the look: `mail`, `location` 1px; `check-circle` 2px; `print` 1.5px. Size 24px next to body text, 20px in lists and the footer, 16px inside small buttons, 14px for the header's print link. No emoji, anywhere.
