# Logos

- `terminal-mark.svg`: the terminal-prompt mark that sits left of the name in the header and footer. Single ink, drawn here in black (`#000000`) with a 1px stroke; on a dark ground use the `Mark` component (or inline the SVG with `stroke="currentColor"`) so it takes `ink`.
- `favicon.svg`: the same mark, white 1.4px square-capped stroke on a solid black tile. Browser tab icon only.

There is no wordmark. The name is set in type: Space Grotesk 300, as the `Mark` component does.
