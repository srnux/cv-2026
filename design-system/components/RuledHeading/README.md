# RuledHeading

A sub-section heading (Space Grotesk 500, 24px) underlined by a full-ink 1px rule.

Use inside a section to split it into columns of named groups: "Certifications", "Languages", "Citizenship".

**Consumer provides:** children (the heading text), optional `as` for the heading level.

- 8px between text and rule, 24px below the rule.
- The rule is `rule` (full ink), never `rule-subtle`.
