# DefinitionList

Term and value pairs on one line each: term left in Inter, value right in Space Grotesk with 0.05em tracking in `ink-muted`, a `rule-subtle` line under each row.

Use for languages and levels, or any short label-value facts.

**Consumer provides:** `items`: `[{ term, value }]`.

- Values are short codes or words ("C2", "Native"). Long values belong in prose.
