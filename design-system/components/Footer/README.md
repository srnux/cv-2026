# Footer

The page footer on the black ground: mark left, links centre, social icons right, a copyright line under a `rule-subtle` divider.

**Consumer provides:** `name`, `links` (`[{ href, label }]`, include legal pages), `social` (`[{ href, icon, label }]`), `copyright` (a full sentence).

- Always black, even if the last section above is black too.
- Links in Inter 400 at 16px, underline on hover.
