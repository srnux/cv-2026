# LanguageSwitch

Language links separated by slashes, "EN / DE", in Space Grotesk 14px with 0.05em tracking.

The current language is medium weight and underlined (`aria-current`); others underline on hover. They are real links to each language's URL, so crawlers follow them; a click may also store the choice.

**Consumer provides:** `languages`: `[{ code, href, onSelect? }]`, `current`, optional `label` for the nav.
