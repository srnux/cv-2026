# SectionHeading

The centred, light-weight title that opens every section, with an optional one-line intro.

Headings on the home page are Space Grotesk **300**, not bold. Hierarchy comes from size and whitespace; the weight stays quiet.

**Consumer provides:** `title`, optional `intro` (one sentence, in `ink-muted`, capped at `measure-intro`).

- One per section, always centred, 48px (`space-12`) above the content.
- 36px on phones, 48px from 768px (`section-title`).
- Title case in English ("Professional Experience"), German nouns as German capitalises them.
